# 常见问题 (FAQ)

## 📖 一般问题 (General Questions)

### Q: Nexus Reader 是什么？
**A:** Nexus Reader 是一个基于免费服务构建的现代化个人云阅读平台。它通过最大化利用 GitHub 和 Cloudflare 的免费服务，将本地 NAS 应用转换为全球可访问的企业级云服务，支持多设备同步、AI 增强功能和离线阅读。

### Q: 为什么选择免费服务？
**A:** 
- **零成本运营**: 完全基于免费服务，无需支付服务器费用
- **企业级性能**: Cloudflare 全球 CDN 提供优秀的性能和可靠性
- **自动扩展**: 免费服务通常具有良好的扩展性
- **学习价值**: 展示如何最大化利用免费资源构建生产级应用

### Q: 系统支持哪些设备？
**A:** 
- **桌面浏览器**: Chrome, Firefox, Safari, Edge (最新版本)
- **移动设备**: iOS Safari, Android Chrome
- **PWA 支持**: 可安装为原生应用体验
- **离线功能**: 支持离线阅读和数据同步

## 🚀 安装和设置 (Installation & Setup)

### Q: 如何安装 PWA 版本？
**A:** 
1. **桌面浏览器**:
   - 访问应用网址
   - 点击地址栏中的安装图标 (📱)
   - 点击"安装"确认

2. **移动设备**:
   - 访问应用网址
   - 点击浏览器菜单中的"添加到主屏幕"
   - 确认安装

3. **验证安装**:
   - 检查桌面/主屏幕是否出现应用图标
   - 点击图标启动应用

### Q: 首次使用需要注册吗？
**A:** 不需要传统的注册流程。系统会自动为每个设备生成唯一标识符，您只需：
1. 首次访问时允许应用创建设备 ID
2. 设置您的阅读偏好（字体、主题等）
3. 开始上传和阅读小说

### Q: 如何在多个设备间同步？
**A:** 
1. 在每个设备上安装并打开应用
2. 在设置中启用"自动同步"
3. 系统会自动同步：
   - 阅读进度
   - 书签和笔记
   - 用户偏好设置
   - 小说库

## 📚 使用功能 (Usage Features)

### Q: 支持哪些小说格式？
**A:** 
- **文本格式**: TXT, MD
- **电子书格式**: EPUB, MOBI (计划支持)
- **压缩包**: ZIP 包含的文本文件
- **在线导入**: 支持从 URL 导入

### Q: 如何上传小说？
**A:** 
1. 点击主页的"+"按钮
2. 选择上传方式：
   - **本地文件**: 选择设备上的文件
   - **URL 导入**: 输入在线小说链接
   - **文本粘贴**: 直接粘贴文本内容
3. 填写小说信息（标题、作者、分类）
4. 点击"上传"完成

### Q: AI 推荐是如何工作的？
**A:** 
- **阅读历史分析**: 基于您的阅读偏好和历史
- **内容相似性**: 分析小说内容的相似度
- **协同过滤**: 参考相似用户的阅读选择
- **实时学习**: 根据您的反馈持续优化推荐

### Q: 语义搜索有什么特别之处？
**A:** 
- **自然语言查询**: 可以用自然语言描述想找的内容
- **概念理解**: 理解查询背后的概念和意图
- **智能匹配**: 即使关键词不完全匹配也能找到相关内容
- **多语言支持**: 支持中英文混合查询

## 🔄 同步和数据 (Sync & Data)

### Q: 同步需要多长时间？
**A:** 
- **阅读进度**: 通常在 5 秒内同步到所有设备
- **书签笔记**: 立即同步到云端
- **用户偏好**: 实时同步
- **小说内容**: 根据文件大小，通常 1-30 秒

### Q: 离线时能做什么？
**A:** 
- **继续阅读**: 访问已缓存的小说内容
- **添加书签**: 离线添加书签和笔记
- **调整设置**: 修改阅读偏好
- **自动同步**: 重新联网时自动同步所有更改

### Q: 如果多个设备同时修改会怎样？
**A:** 
系统使用"最后写入获胜"策略：
1. **检测冲突**: 自动检测数据冲突
2. **时间戳比较**: 以最新的修改为准
3. **智能合并**: 对于不冲突的数据进行合并
4. **用户通知**: 重要冲突会通知用户

### Q: 数据存储在哪里？
**A:** 
- **云端存储**: Cloudflare KV (加密存储)
- **本地缓存**: 浏览器 IndexedDB (离线访问)
- **CDN 缓存**: Cloudflare CDN (性能优化)
- **原始数据**: 您的 NAS 设备 (主要存储)

## 🛡️ 安全和隐私 (Security & Privacy)

### Q: 我的数据安全吗？
**A:** 
- **端到端加密**: 所有敏感数据在传输和存储时都经过加密
- **零信任架构**: 实施零信任安全原则
- **隐私合规**: 符合 GDPR 等隐私法规要求
- **最小权限**: 只收集必要的数据

### Q: 会收集哪些数据？
**A:** 
- **必要数据**: 设备 ID、阅读进度、用户偏好
- **匿名分析**: 性能指标、错误日志（已匿名化）
- **不收集**: 个人身份信息、敏感个人数据
- **用户控制**: 您可以随时删除所有数据

### Q: 如何删除我的数据？
**A:** 
1. 进入设置页面
2. 点击"数据管理"
3. 选择要删除的数据类型：
   - 阅读历史
   - 书签笔记
   - 用户偏好
   - 所有数据
4. 确认删除操作

## ⚡ 性能和优化 (Performance & Optimization)

### Q: 为什么加载速度这么快？
**A:** 
- **全球 CDN**: Cloudflare 全球边缘节点
- **智能缓存**: 多层缓存策略
- **边缘计算**: API 在边缘节点处理
- **资源优化**: 自动图片优化和压缩

### Q: 应用占用多少存储空间？
**A:** 
- **PWA 本体**: 约 2-5 MB
- **缓存内容**: 根据阅读的小说数量而定
- **离线数据**: 可在设置中管理缓存大小
- **自动清理**: 系统会自动清理过期缓存

### Q: 如何优化性能？
**A:** 
1. **启用缓存**: 确保浏览器缓存已启用
2. **网络优化**: 使用稳定的网络连接
3. **定期清理**: 清理不需要的离线内容
4. **更新浏览器**: 使用最新版本的浏览器

## 🔧 故障排除 (Troubleshooting)

### Q: 应用无法加载怎么办？
**A:** 
1. **检查网络**: 确保网络连接正常
2. **清除缓存**: 清除浏览器缓存和数据
3. **重新安装**: 卸载并重新安装 PWA
4. **检查状态**: 访问 [状态页面](https://status.nexus-reader.example.com)

### Q: 同步不工作怎么办？
**A:** 
1. **检查网络**: 确保所有设备都有网络连接
2. **重新登录**: 在设置中重新生成设备认证
3. **手动同步**: 在设置中点击"立即同步"
4. **重置同步**: 如果问题持续，可以重置同步状态

### Q: 上传失败怎么办？
**A:** 
1. **检查格式**: 确保文件格式受支持
2. **检查大小**: 单个文件不超过 50MB
3. **网络稳定**: 确保网络连接稳定
4. **重试上传**: 稍后重试或分章节上传

### Q: PWA 安装失败怎么办？
**A:** 
1. **浏览器支持**: 确保浏览器支持 PWA
2. **HTTPS 连接**: 确保使用 HTTPS 访问
3. **清除数据**: 清除浏览器数据后重试
4. **手动添加**: 使用浏览器的"添加到主屏幕"功能

## 🤖 AI 功能 (AI Features)

### Q: AI 推荐不准确怎么办？
**A:** 
1. **提供反馈**: 对推荐结果点赞或点踩
2. **完善资料**: 在偏好设置中完善您的兴趣标签
3. **增加阅读**: 多阅读不同类型的小说帮助 AI 学习
4. **重置推荐**: 在设置中重置推荐算法

### Q: 语义搜索找不到内容？
**A:** 
1. **换个表达**: 尝试不同的关键词或表达方式
2. **使用标签**: 结合分类标签进行搜索
3. **检查拼写**: 确保搜索词拼写正确
4. **等待索引**: 新上传的内容可能需要时间建立索引

### Q: AI 分类错误怎么办？
**A:** 
1. **手动修正**: 在小说详情页手动修改分类
2. **提供反馈**: 报告错误分类帮助改进算法
3. **添加标签**: 手动添加正确的标签
4. **重新分析**: 在设置中重新运行 AI 分析

## 💰 免费服务限制 (Free Service Limits)

### Q: 有哪些使用限制？
**A:** 
- **存储空间**: 1GB KV 存储（智能管理）
- **API 请求**: 每天 100,000 次 Worker 请求
- **AI 功能**: 每天 10,000 次 AI 请求
- **图片处理**: 每月 100,000 次图片转换

### Q: 超出限制会怎样？
**A:** 
- **自动优化**: 系统会自动优化资源使用
- **智能清理**: 自动清理过期和不常用数据
- **降级服务**: 临时禁用非核心功能
- **恢复时间**: 通常在下个计费周期自动恢复

### Q: 如何监控使用情况？
**A:** 
1. 访问设置中的"资源使用"页面
2. 查看实时使用统计
3. 设置使用警告阈值
4. 接收使用情况通知

## 📊 技术细节 (Technical Details)

### Q: 使用了哪些技术？
**A:** 
- **前端**: React + TypeScript + PWA
- **后端**: Cloudflare Workers + KV Storage
- **AI**: Cloudflare Workers AI + OpenAI
- **CDN**: Cloudflare CDN + Images
- **CI/CD**: GitHub Actions
- **监控**: 自建分析系统

### Q: 为什么选择这些技术？
**A:** 
- **免费额度**: 所有服务都有慷慨的免费额度
- **全球性能**: Cloudflare 全球网络保证性能
- **开发效率**: 现代技术栈提高开发效率
- **可扩展性**: 架构支持未来功能扩展

### Q: 系统架构是怎样的？
**A:** 
```
用户设备 (PWA)
    ↓
Cloudflare CDN (全球缓存)
    ↓
Cloudflare Workers (边缘计算)
    ↓
Cloudflare KV (数据存储)
    ↓
GitHub Actions (CI/CD)
    ↓
NAS 设备 (原始数据)
```
