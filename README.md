## 🚀 快速开始

### 1. 一键部署（推荐）

```bash
# 克隆项目
git clone <your-repo>
cd nexus-reader-project

# 自动构建和部署到 Cloudflare
./deploy.sh

# 推送到 GitHub 触发完整自动化部署
git add .
git commit -m "Deploy to Cloudflare"
git push origin main
```

### 2. 配置 Secrets

在 GitHub 仓库设置中添加：

```bash
# Cloudflare 配置
CLOUDFLARE_API_TOKEN=your_cf_token
CLOUDFLARE_ACCOUNT_ID=your_cf_account_id

# GitHub 配置
GITHUB_TOKEN=github_token  # 自动提供

# 可选：HuggingFace (CF 绕过服务)
HF_TOKEN=your_hf_token
```

### 3. 访问应用

部署完成后自动可用：

- **前端应用**: `https://nexus-reader.pages.dev`
- **API 服务**: `https://api.nexus-reader.pages.dev`
- **文档站点**: `https://your-username.github.io/nexus-reader`
